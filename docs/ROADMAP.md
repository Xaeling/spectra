# StatAura 产品与技术路线图

> 版本：v0.1 · 2026-11-11
> 目标：用 Rust 重做一个 **GraphPad Prism 级别的科研数据分析与出版级绘图工具**，在交互流畅度、视觉品质与导出精度上全面超过前身 Spectra。

---

## 0. 结论先行

Spectra 的问题不在功能数量，而在三件事：

1. **UI 框架不在掌控内**：charis-ui 0.1 的拖拽 / 点击 / 右键事件语义未经证实，Spectra 自己的文档承认核心交互全压在这上面。
2. **重绘策略错了**：每帧重跑 plotters 位图管线；而 plotters 不支持旋转文字，Y 轴标题只能逐字符竖排。
3. **没有设计系统**：颜色、间距、圆角散落各处，最终是“像 Prism 的控件堆叠”。

StatAura 的答案：**成熟 UI 框架 + 自研矢量绘图内核 + 单一设计系统 + 渲染缓存。**

---

## 1. 技术选型

| 层 | 选择 | 理由 |
|---|---|---|
| 窗口 / UI | eframe + egui 0.37 | 输入、焦点、滚动、IME、多视口都成熟；视觉可完全自定义 |
| 绘图 | 自研 SPE：tiny-skia + ab_glyph | 文字旋转、CJK、抗锯齿、全路径导出 |
| 数据 / 工程 | serde + JSON（`.aura`） | 可读、可 diff、便于排障 |
| 导出 | image + 自写 SVG/PDF | 文字转曲，零字体依赖 |
| 统计 | 纯 Rust + 单元测试 | 结果可验证，不引黑盒 C 库 |

### 为什么不用 plotters 做最终渲染

同尺寸对照实验（900×600，正弦线 + 散点 + 中文标题）：

- 文字不能旋转，Y 轴标题只能逐字符竖排；
- 默认字体没有 CJK，“中文”直接缺字；
- 圆点是硬边，300 dpi 下可见锯齿；
- 刻度避让、图例、误差棒、显著性括号都要重画。

结论：绘图内核必须自研。`tiny-skia` 提供抗锯齿光栅，`ab_glyph` 提供字形轮廓；文字统一转路径后，屏幕、PNG、SVG、PDF 完全一致。对照图见 `docs/screenshots/plotters-probe.png`。

## 5. 风险与对策

| 风险 | 对策 |
|---|---|
| 自研绘图工作量爆炸 | 先做 11 种高频图，场景 IR 一次设计到位；其余 M8 增量 |
| PDF 字体/坐标出错 | 文字全部转曲；只用最小指令集；结构自检 + 实际阅读器验证 |
| 大文件 JSON 变慢 | v0.2 起表格数据改 CSV-in-ZIP，manifest 保持 JSON |
| egui 升级破坏 API | 锁 0.37，升级单独立项，egui 依赖收敛在 `app/` |
| 中文排版 | 内置 MiSans、逐字 fallback、导出转曲 |
| 统计口径争议 | 每个检验写明假设与公式；方法行随结果展示 |
| 快照撤销内存 | 超大表改操作日志；v0.1 上限 80 步 |
