# 科研配图规范（可执行约束）

> 这份文档是 `src/plot/spec.rs` 的依据。**规范不只是写在这里，而是由代码检查**：
> 检查器底部的「出版规范」区块每帧对当前图表跑一遍 `spec::audit()`，
> 违反硬指标就报「必须改」，建议性条目报「建议改」，并给出具体改法。

## 1. 硬指标

| 项目 | 要求 | 代码常量 |
|---|---|---|
| 图内最小字号 | ≥ 7 pt（按最终印刷尺寸计） | `MIN_FONT_PT` |
| 最细线宽 | ≥ 0.25 pt | `MIN_LINE_PT` |
| 坐标轴线宽 | 0.5 – 1 pt | `AXIS_WIDTH_RANGE` |
| 单栏 / 双栏宽 | 85 mm / 170 mm | `COLUMN_MM` |
| 位图分辨率 | ≥ 300 dpi | `MIN_DPI` |
| 色彩模式 | 投稿阶段 RGB；印刷可能要求 CMYK | — |
| 文件格式 | 矢量优先（PDF/SVG/EPS），位图用 TIFF，避免 JPEG | — |

**为什么字号是硬指标**：常见错误是在大画布上作图，缩到单栏后字看不清。
字号用 pt 定义（pt 本身就是印刷单位），所以可以直接比阈值，不受画布缩放影响。

## 2. 色盲友好

约 8% 男性有红绿色觉障碍。规则：

- **避免红绿对比**；推荐蓝-橙、蓝-红，或 viridis 类连续色阶；
- 检查只看**图上实际用到的颜色**：8 色方案只画 3 组时，第 6/7 色的冲突与这张图无关，
  误报会让提示失去可信度（`audit_series` 的 `series` 参数）；
- 判据是色相落在红区（≈350°–25°）与绿区（≈80°–160°），且彩度 > 0.35——
  低饱和的粉 / 浅绿不算强红绿对比。

实现：`red_green_conflict()`。

## 3. 轴标题

- 格式「量的名称/单位」，例如「体重/(g)」「浓度/(mg·L⁻¹)」；
- 无量纲量（比例、频数、计数）不强制单位，但**不能为空**；
- 饼图 / 环形图 / 热图无 Y 轴，不检查。

实现：`has_unit()`。

## 5. 与技能规范的关系

本文件的口径来自三处，取交集（最严的那条）：

- **`jifan-peitu-guifan`**（科研配图规范表）：分辨率 ≥300 dpi、字号 ≥7 pt、
  单栏 85 mm / 双栏 170 mm、线宽 ≥0.25 pt、轴 0.5–1 pt、避免红绿；
- **`academic-chart-layout`**（学术图表绘制助手）：字号 ≥8 pt、轴标题「量/单位」、
  描边 0.5–1 pt、四周留 2–3 mm 安全边；
- **`like-sci-figures`**（LIKE 学术配图）：300 DPI 输出、期刊风格与配色的参考。

字号取 7 pt 而不是 8 pt：前者是普遍下限，后者是 Arial/Times 的建议值，
本项目的主题字号都在 8.4 pt 以上，实际上两条都满足。

## 6. 还没做的

- **CMYK 预演**：投稿若要求 CMYK，高饱和纯色会掉色，目前只在文档里提示，没有转换预览；

- **多子图 (a)(b)(c) 标号**：尚未做分面 / 拼图功能。

## 7. 渲染后几何校验（render-then-verify）

来源于 Nature `figure-style` §9.1：**画完要看像素**。`spec::audit()` 只能看参数
（字号、线宽、配色），看不出「点画到框外 3px」「中位数线刺出箱体」这类问题——
它们必须在下笔时记录。

实现：`Ctx::check_pt / check_rect / check_poly`，在 `plot::render` 返回的
`Render.violations` 里累积。每次渲染都开，开销可忽略。

| 检查 | 判据 | 容差 |
|---|---|---|
| 标记点 | 圆心到绘图区边界 ≥ 半径 | `r` |
| 柱 / 色块 | 矩形完全落在绘图区内 | 半个描边宽 |
| 轮廓 / 填充 | 每个顶点都在绘图区内 | 0.5 px |

**什么地方会失败**（都是真实出现过的问题，现在都有回归测试）：

- 横向柱条的散点：轴域只按 `mean ± SEM` 定，单个观测跑到框外（最远 83px）；
- 箱线图中位数线：2pt 描边画到 `cx ± half`，两端各多出 1pt，比箱体还宽；
- 直方图：轴域 `[min, max]` 没有留白，首尾两根柱子压在坐标轴上；
- 山脊图：网格止于轴端点，密度还有 1%，两端出现垂直切边。

回归闸门：`plot::geometry_tests::所有图型都不越出绘图区` 把 24 种图型、4 套主题、
3 种画布尺寸各画一遍，`violations` 必须为空。

## 8. 逐图型的作图口径（本轮核对后固化）

| 项目 | 口径 | 出处 |
|---|---|---|
| 刻度线 | **朝外**；朝内会压在柱子与数据点上 | Prism / Nature 默认 |
| 坐标轴、边框 | 平头端帽；圆头会在每个角多出半个线宽 | — |
| 直方图 | 轴在分箱两侧各留 2% 余量；多组并排才留缝 | ggplot2 `expand` |
| 箱线图 | 中位数线止于箱体内沿；须止于栅栏内最远的观测 | Tukey |
| 小提琴 | 内嵌箱体与琴身**同色填充**，只把边框加深；纯白块会读成「挖了个洞」 | Prism + 用户口径 |
| 山脊图 | 密度两端收窗到 0；自上而下绘制、近不透明填充 | ggridges |
| 面积图 | 多序列按「大到小」画、近不透明分带；线在最后统一画 | — |
| 热图 | ≤200 格时每格印数值，文字按底色亮度选白/黑（≥4.5:1） | `figure-style` §6.5 / §5.5 |
| 图例 | 柱 / 面积类的色块会占住右上角 → 自动改到右侧外部 | `figure-style` §7.3 |
| 色块上的文字 | 按相对亮度在白与近黑间二选一，取对比度更高者 | `figure-style` §5.5 |

## 9. 结构断言与场景诊断

几何自检只能回答「有没有跑出框」；「该画的元素画了没有」要靠另一层：

- **`examples/diag.rs`**（`cargo run --release --example diag`）：渲染后遍历
  `Render.scene.ops`，统计无描边白块、实心/空心标记、宽幅半透明填充、
  细横线/细竖线条数。用它定位过三个问题：回归置信带 3×801px 叠色、
  箱线图离群点画成实心圆、小提琴内部只剩一块无描边白矩形。
- **`plot::structure_tests`**：把结论钉成断言——
  离群点必须空心、小提琴必须同时有 IQR 箱与中位线且无白块、
  多序列回归不许出现半透明宽带、置信带不得铺满轴、>120 点不逐点画标记。

### 9.1 几个图型元素的口径

| 元素 | 要求 |
|---|---|
| 离群点（箱线/小提琴） | **空心圈**，与数据点区分；实心会被当成多余观测 |
| 小提琴内嵌箱线 | 须线（含须帽）+ IQR 箱（**与琴身同色填充 + 更深描边**）+ 中位横线 + 离群点，缺一不可 |
| 置信带 | 只覆盖数据区间；单序列填充，多序列改**描边虚线**（半透明叠色会糊成灰） |
| 标记点 | 单序列 >120 点时只画线；逐点标记会叠成「毛毛虫」并盖住曲线 |

## 10. 文本碰撞检测与图注统计行

**文本碰撞（§9.1 文字层）**：`Ctx::text` 记录每行轴对齐文字的外框，
`text_collisions()` 在渲染末尾查两条规则——

| 检查 | 判据 | 容差 |
|---|---|---|
| 标签互相压 | 两外框去噪后（四周缩 1px）交叠 > 1px | 1 px |
| 标注越框 | 中心在绘图区内的文字必须整个在框内 | 1.5 px |

旋转文字不参与互压检查：倾斜排布的相邻标签（旋转刻度、Y 轴标题）的 AABB
天然重叠，而它们正是靠倾斜避让的——检查它们只会得到误报。

**图注统计行**（画布左下、x 轴标题之下，小字 muted）：规范要求但不该
挤在绘图区里的推断信息都走这一行：

| 图型 | 内容 | 出处 |
|---|---|---|
| 分类图 + 显著性括号 | 检验全名（双侧）、校正、效应量与 95% CI、各组 n | G4/G3 |
| 生存图 | log-rank χ²/p、HR（带方向）及 95% CI | E2-5 |
| 回归（单组） | 斜率 b 及 95% CI | C1-2 |
| 回归（多组） | ANCOVA 交互项 F/p + 结论（斜率是否真有差异） | C1-4 |

p 值写 `p = 0.012` / `p < 0.001`（禁 `p = 0.000`）。
