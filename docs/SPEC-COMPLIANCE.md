## 1. 图层清单（现行 z-order）

```
z0 背景 + 网格（draw_grid）
z1 参考线（零线 / 网格 / 显著性基准）
z2 分布与置信带（KDE 琴身、面积带、CI 带、山脊）
z3 统计摘要（箱线五元素、拟合线、均值柱、误差棒）
z4 原始数据点（jitter / 散点，最后一遍绘制）
z5 标注（显著性括号、风险人数表、图例、轴标题、面板文字）
```

`render_xy` 用「填充 → 线 → 点」三遍绘制，保证 G6「原始点不得被拟合线盖住」。
填充类图型图例自动外置，保证 G6「图例不得压数据」。
